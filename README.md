# DSH Web

Плагин Orca: запускает `dsh web` в фоновом терминале и открывает Web UI в браузерной вкладке Orca.

- Кнопка **DSH Web** в статус-баре открывает панель справа.
- В панели: открыть вкладку, перезапустить, остановить, показать терминал.
- Команды «DSH Web: панель», «открыть», «остановить», «перезапустить» есть и в палитре.
- Статус-бар зелёный, когда сервер текущего проекта работает.
- Сервер живёт в терминале Orca, поэтому работают штатные хуки и статус DSH.
- Повторный запуск переиспользует сервер; вкладок может быть несколько.
- Если сервер умер, следующее открытие поднимет его заново.
- Один сервер на каждый хост: локальный и удалённые workspace не мешают друг другу.
- Для удалённого workspace вкладка открывается с привязкой к нему, чтобы Orca
  пробросила loopback-адрес DSH через своё SSH-соединение.

Ограничение: Orca не позволяет плагинам добавлять строку в список агентов. Плагин не заменяет
встроенную строку DeepSeek Harness (она запускает `dsh-tui`), а добавляет отдельную команду.

## Проверка
