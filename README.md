# DSH Web

Плагин Orca: запускает `dsh web` в tmux-сессии `orca-dsh-web` и открывает Web UI в браузерной вкладке Orca.

- Кнопка **DSH Web** в статус-баре открывает вкладку; если сервер не запущен, поднимает его.
- Команды «DSH Web: открыть», «остановить», «перезапустить» есть в палитре.
- Статус-бар зелёный, когда tmux-сессия и сервер живы.
- Повторный запуск переиспользует сервер; вкладок может быть несколько.
- Остановка и перезапуск управляют tmux-сессией; вручную: `tmux attach -t orca-dsh-web`.
- Лог: `~/.cache/orca-dsh-web/dsh-web.log`.

Ограничения:

- Работает только на локальном хосте. Для удалённого workspace нужен отдельный режим.
- DSH больше не живёт в терминале Orca, поэтому штатные хуки и статус DSH в Orca не работают.
- Нужен установленный `tmux`.

Ограничение: Orca не позволяет плагинам добавлять строку в список агентов. Плагин не заменяет
встроенную строку DeepSeek Harness (она запускает `dsh-tui`), а добавляет отдельную команду.
